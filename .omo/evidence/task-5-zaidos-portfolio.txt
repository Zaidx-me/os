== 5. Sandbox-specific e2e run workaround (NOT needed in CI) ==
  This docker sandbox has no browser system libs and no fonts. The chromium
  binaries download fine (INSTALLATION_COMPLETE present) but launch validation
  fails. Workaround used for local `npx playwright test`:
    export LD_LIBRARY_PATH=/tmp/opencode/pwlibs/l          (extracted .debs: glib,
      nss, nspr, atk, atspi, dbus, xcomposite, xdamage, xfixes, xrandr, gbm,
      xkbcommon, asound, drm, xi, xrender)
    export PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1
    export FONTCONFIG_FILE=/tmp/opencode/fonts.conf        (points at extracted
      DejaVu Sans ttf; without fonts text has zero-width glyph boxes and
      Playwright reports links as "hidden")
  Playwright browser cache: ~/.cache/ms-playwright (chromium-1234,
  chromium_headless_shell-1234, ffmpeg-1011).
