STORE CONTRACT (consumed by todo 8 waybar + todo 12 lib/wm/actions.ts)
---------------------------------------------------------------------
- WORKSPACE_IDS = [1,2,3,4,5] (const), WORKSPACE_LABELS = ["term","proj","web","soc","game"]
- workspaceLabel(ws), isWorkspaceId(ws) guards
- State: workspaces: Record<WorkspaceId, { windows: string[]; focused: string|null }>, activeWs
- openInWorkspace(appId, ws?): string  -> win-<counter> monotonic id, defaults to activeWs,
  pushes + focuses, returns id
- closeWindow(id): removes ONLY from owning ws; focused window -> focus falls to the
  window that followed it (or last remaining, or null)
- moveWindow(id, ws): remove from old, append to new, focus in new; old ws focus falls
  back when the moved window was focused; same-ws move never duplicates
- focusNextInWs(ws): cycles focus within ws's ordered list (wraps), no-op when empty
- setActive(ws), getWindowWs(id): WorkspaceId|null
- Selectors: selectWorkspace(ws) -> {windows, focused} (stable ref), selectActiveWs
- NEVER persisted: no persist middleware; test asserts store.persist === undefined

CRITICAL INVARIANTS PROVEN BY TESTS (22/22 pass)
------------------------------------------------
1. window exists in EXACTLY ONE workspace at all times (no dup across ws, none in zero ws)
   - expectExactlyOneWorkspace() helper asserts unique union + getWindowWs != null
   - property-style test: mixed open/close/move/focus/setActive sequence holds invariant
2. closeWindow removes from the owning workspace only (other ws untouched)
3. closing the focused window -> focus falls to next remaining window (or null when empty)
   - middle-window close: next window becomes focused
   - last-window close: focus -> null
   - closing non-focused window: focus untouched
4. moveWindow relocates without duplication and updates focus in BOTH workspaces
   - same-workspace move does not duplicate (regression guard)
   - invalid target workspace / unknown window = safe no-ops
5. focusNextInWs cycles within a workspace, no-op on empty ws
6. WorkspaceView renders empty hint exactly: "Nothing here yet. Press Super+Space"
   - renders ONLY active workspace's windows (data-testid="ws-window", key=id)
7. no persistence middleware on the store
