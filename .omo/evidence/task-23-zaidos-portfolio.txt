- TURBOPACK LOADER GOTCHA (the build blocker): `import.meta.glob` with
  `query: "?raw"` works natively in Vite (vitest) but Turbopack rejects
  `.md` with "Unknown module type ... Use a known file extension, or
  register a loader for it" — EVEN with `turbopack: { rules: { "*.md":
  ["raw-loader"] } }` (bare-array form). The documented form is the OBJECT
  form: `turbopack: { rules: { "*.md": { loaders: ["raw-loader"],
  as: "*.js" } } }` (next-config-js/turbopack.md "Configuring webpack
  loaders": rules map extensions to { loaders, as }; `as` declares the
  output module type). With the object form the build compiles. raw-loader
  installed as devDependency. The `?raw` query stays in the glob for Vite;
  the loader rule satisfies Turbopack.
- Articles body re-fetched from zaidx.me (DNS still up) — de-risks the
  todo-45 cutover (owner's domain / content source). Bodies are the source
  of truth; the .md files are cleaned verbatim copies.
