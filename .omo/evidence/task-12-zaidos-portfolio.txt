  (focus() no-ops when already top; test asserts z + nextZ stable).
- minimize preserves state (asserts x/y/w/h/z/title/mode/maximized intact).
- toggleMaximize toggles (false -> true -> false).
- setBounds clamps: pure clampWindowBounds({100,100},{vw:200,vh:200})

  setBounds(100,100) on a mocked 200x200 viewport yields the same.
- focus() refuses cross-workspace windows (getWindowWs(id) !== activeWs).

  no dangling focus (workspaces focused falls to next window too).

  platforms; plain/wrong-modifier keys resolve null.
- Both store mutations always in the same synchronous handler
  (openApp = openInWorkspace THEN wm.open; closeWindow = wm.close THEN
  workspaces.closeWindow; moveWindowToWorkspace = moveWindow + raise/bounds).
