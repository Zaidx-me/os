FONTS
-----
- Source: next/font/google — build environment HAS network access
  (fonts.googleapis.com returned 200; npm registry 200), so the google
  route was used and NO self-host/local fallback was needed.
- Inter:         weights 400,500,700, subsets latin, variable "--font-sans"
- JetBrains_Mono: weights 400,500,700, subsets latin, variable "--font-mono"
- Verified against local Next docs (node_modules/next/dist/docs/...13-fonts.md
  + font.md API ref): `variable` option + weight arrays supported in 16.3.0.
  Weight arrays map to per-weight static instances in the css2 URL
  (get-google-fonts-url.js: variants joined as wght@400;500;700).
- Wiring: layout.tsx <html className="{inter.variable} {jetbrainsMono.variable}">
  overrides the @theme fallback stacks in globals.css --font-sans/--font-mono
  (class specificity beats :root), so font-sans/font-mono utilities and
  body font-family resolve to the actually-loaded faces. globals.css @theme
  tokens untouched (only the declared fallback stacks remained).
- Kept: html lang="en" h-full antialiased, body min-h-full flex flex-col.
- Removed: Geist / Geist_Mono (create-next-app default). Metadata block left
  as-is — SEO owns root metadata in a later todo (34).

ICON SYSTEM
-----------
- src/components/ui/Icon.tsx — thin typed wrapper around lucide-react:
  exported ICONS map drives IconName union (autocomplete + type errors),
  props = name + size (default 16) + LucideProps passthrough, aria-hidden
  by default, currentColor theming (lucide default). ~56 icons curated for
  the OS (waybar, launcher, window chrome, apps, terminal).
- src/components/ui/AppIcon.tsx — custom rice-style SVG per appId for all
  11 ids (about, projects, skills, experience, resume, contact, articles,
  settings, terminal, chat, chess). Stroke-based thin geometric glyphs,
  strokeWidth 1.5, round caps, currentColor, role="img" +
  aria-label=<humanized label> (e.g. "Terminal"). NO emoji. Unknown ids get
  a deterministic generic app tile (rect + center dot) — never throws.
- src/components/ui/AppIcon.test.tsx — 4 tests: accessible name for
  terminal ("Terminal"), fallback for unknown id (no throw + rect/circle
  anatomy), all 11 appIds render, currentColor theming. Explicit
  `import { describe, expect, it } from "vitest"` per repo convention.
- lucide-react 1.x NOTE: brand icons (Github, Linkedin) REMOVED from the
  package — they are undefined exports. Waybar social links (todo 8) must
  use AtSign/Link or a custom brand glyph. Documented in Icon.tsx comment.

APP ICONS (metadata)
--------------------
- src/app/icon.svg — ZaidOS mark: 64x64, dark rounded square #0a0c10
  (rx 14) + hairline #2a2f3d border + green #39FF14 terminal prompt glyph
  (chevron "M18 26l9 8-9 8" stroke 5 + underscore cursor rect 36,31 13x6).
  No external assets. Replaces create-next-app default (repo only had
  favicon.ico; favicon.ico left untouched — not in todo scope).
- src/app/apple-icon.png — 512x512 PNG, same mark. Generation method:
  `sharp` installed ad-hoc in /tmp/opencode/pnggen (NOT added to project
  package.json), script render.mjs rasterized src/app/icon.svg via sharp's
  librsvg input (density 300, resize 512x512) -> png. No imagemagick /
  rsvg-convert / inkscape / PIL available in this sandbox; npm registry
  reachable so sharp was installable. Verified with a node script reading
  the PNG signature (89504e470d0a1a0a = VALID) + IHDR (512x512, bitDepth 8,
  colorType 6 RGBA); 26,141 bytes. (No `file` binary in sandbox.)
