LAYER MODEL (bottom -> top)
---------------------------
Wallpaper z-0 / DesktopIcons z-10 (icon grid + right-click surface) /
WorkspaceView z-20 (pointer-events-none; tiles pointer-events-auto) / Waybar z-40 /
ContextMenu z-50. Windows float ABOVE icons; the window layer passes events through
to the desktop except where a window tile actually sits — so a right-click on an
open window never reaches the desktop context handler, and empty-desktop right-clicks
always open the menu.
